# Microsoft Fabric — Medallion Architecture + Data Mesh

> Construção de uma plataforma moderna de dados utilizando Microsoft Fabric, combinando **Medallion Architecture** e princípios de **Data Mesh**, com ingestão, transformação, organização por domínios, Deployment Pipelines e disponibilização de dados através do Power BI.

---

## 📌 Sobre o Projeto

Este projeto demonstra, na prática, como construir uma arquitetura moderna de dados utilizando o **Microsoft Fabric**.

A solução combina duas abordagens complementares:

- **Medallion Architecture** — responsável pelo processo de ingestão, tratamento e refinamento dos dados.
- **Data Mesh** — responsável pela organização dos dados por domínios de negócio e pela visão dos dados como produtos.

A plataforma foi concebida para conduzir os dados desde as fontes de origem até ao consumo analítico, passando por diferentes níveis de transformação e disponibilização.

O resultado final é uma solução que permite transformar dados brutos em **produtos de dados confiáveis e preparados para análise**, consumidos através de modelos semânticos e relatórios Power BI.

---

## 🎯 Objetivos

Os principais objetivos deste projeto são:

- Demonstrar a implementação de uma **Medallion Architecture** no Microsoft Fabric.
- Aplicar princípios de **Data Mesh** na organização dos dados.
- Implementar processos de ingestão e transformação de dados.
- Organizar dados nas camadas **Bronze, Silver e Gold**.
- Estruturar dados por **domínios de negócio**.
- Criar produtos de dados orientados às necessidades analíticas.
- Desenvolver modelos semânticos para consumo no Power BI.
- Criar relatórios e indicadores para análise de negócio.
- Utilizar **Deployment Pipelines** para promover alterações entre ambientes.
- Demonstrar a disponibilização dos relatórios através de **Power BI Apps**.
- Explorar cenários de consumo por utilizadores internos e externos.
- Documentar as decisões e componentes da arquitetura.
